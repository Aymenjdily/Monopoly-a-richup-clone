- Only the host can edit settings. Everyone else sees them read-only.
- Changes are server-validated and broadcast live, like seats.
- Settings lock when the game starts.
- Auctions, trading and timers stay out of scope.

## Variants

- **E1 — Sidebar** (`variant-E1-lobby.png`): the rules panel is always visible on the right,
  and the stage shrinks to fit. Everything is on one screen, but the stage and pawns get smaller.
- **E2 — Rules sheet** (`variant-E2-lobby.png`): a "⚙ Room rules" button in the header opens
  a centered sheet with money on the left and rules on the right, plus Save and "Reset to standard".
  The lobby stays uncluttered, but the rules are hidden until the sheet is opened.
- **E3 — Rule tiles** (`variant-E3-lobby.png`): each setting is a mini board tile in a row
  above the stage. It's playful, in the board's language, and always visible. It's the most
  compact, but the descriptions are gone, so each setting has a label only.
