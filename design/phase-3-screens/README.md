# Design variants — Phase 3 (home + lobby)

**PICKED: variant C3** (with shader background added after the pick).
Locked copies live in `design/selected/` (PNG + source HTML). Frozen reference for
Phase 3+ UI, reproduced exactly in Tailwind via `app/globals.css` utilities
(`.bg-shader`, `.bg-spotlight`, `.bg-vignette`, `.grain`).
Rendered to PNG with `scripts/shoot-designs.ps1` (headless Edge, 1600×1000).

## Variant A — "Neon glass" (richup-adjacent)
- Files: `variant-A-home.html/png`, `variant-A-lobby.html/png`
- Dark navy bg with soft radial glow, frosted-glass cards, blue→cyan gradient CTAs,
  monospace paved room code, three-column lobby seats.
- Language: techy, modern SaaS feel.

## Variant B — "Classic table & brass"
- Files: `variant-B-home.html/png`, `variant-B-lobby.html/png`
- Deep felt-green background, double-rule gold borders, Georgia serif, warm brass
  buttons, diamond-shaped pawn glyphs.
- Language: old-money boardroom, Monopoly-heritage feel.

## Variant C — "Playful bold" (richup.io's actual tone)
- Files: `variant-C-home.html/png`, `variant-C-lobby.html/png`
- Cream bg with floating pastel dots, thick black outlines, hard-offset shadows,
  pink/yellow CTAs, emoji dice, playful microcopy ("Bankrupt them!").
- Language: loud, fun, arcade-poster.
